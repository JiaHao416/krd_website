## Phase Goal

**As a** 官網訪客, **I want to** 在 8 個商品分類頁與首頁熱銷輪播看到家人在後台維護的商品（含價格、載入中、失敗可重試、沒有商品的明確畫面）, **so that** 我看到的商品資訊與 KRD 實際上架的一致，遇到問題也知道發生什麼事。

<objective>
分類頁切片：訪客打開任一舊網址，看到後端商品；載入中、失敗（可重試）、沒有商品、切換排序、資料被截斷都有明確畫面。

Purpose: 這是本 phase 主要的使用者價值——8 個分類頁完全改讀後端公開 API，且所有舊網址不失效。視覺沿用既有深色 slate 版面（UI-SPEC），不做改版；資料與狀態邏輯留在 useProducts，頁面只依 status 分支渲染。
Output: productPageViews 設定、ImagePlaceholder、改寫的 ProductPageTemplate 與 App.tsx，以及 App／商品頁元件測試。
</objective>

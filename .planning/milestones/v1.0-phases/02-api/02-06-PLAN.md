## Phase Goal

**As a** 瀏覽 KRD 官網的客戶, **I want to** 在分類頁的格狀檢視看到完整的商品卡片（名稱、價格、描述摘要與「點擊查看大圖」提示）, **so that** 不會因內容被裁切而看不到資訊或操作提示。

<objective>
關閉 02-UAT.md 唯一的 gap（第 3 項，severity major）：grid 卡片固定 `h-96`、圖片 `h-64`，product-info（`p-6`）內的名稱 `line-clamp-2 min-h-[2.5rem]` + 價格行（`mb-2`）+ 描述 `line-clamp-2` + 底部「點擊查看大圖」列超出卡片底部。

orchestrator 已在本機 dev server（1280px 視窗、grid 卡片寬 192px）以 XHR 改寫實測「底部列底緣距卡片底緣」（負值＝被裁）：

| 組合 | 有描述 | 無描述 |
|------|--------|--------|
| 現狀（line-clamp-2、p-6、價格 mb-2） | -24px | 15px |
| 只改描述 line-clamp-1 | -4px（仍被裁） | — |
| line-clamp-1 + pt-4 | 4px | 23px |
| **line-clamp-1 + py-4 px-5 + 價格 mb-1（採用）** | **8px** | **17px** |

價格行永遠存在（有價 priceText／無價「價格洽詢」），所以「長名＋價」與「長名」結果相同；名稱有 `min-h-[2.5rem]` + `line-clamp-2`，卡片內容高度不隨卡片寬度變。

本計畫採用上表最後一組：grid 描述 `line-clamp-1`、grid `.product-info` 加 `py-4 px-5`、grid 價格行 `mb-1`。`h-96`、`h-64` 不變，list 卡片不變（依 02-UI-SPEC §2「放不下時優先保價格、描述其次」）。

Purpose: 讓 PROD-04（價格顯示）與「點擊查看大圖」提示在 grid 卡片的實際版面中完整可見。
Output: 修改後的 `ProductCard.tsx`（只改這個檔案）與新增斷言的 `ProductCard.test.tsx`。

</objective>

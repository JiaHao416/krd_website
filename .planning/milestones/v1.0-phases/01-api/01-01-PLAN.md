## Phase Goal

**As a** 官網開發者, **I want to** 用 `npm test` 跑測試、並在本機 `npm run dev` 透過 proxy 讀到後端商品資料, **so that** 之後把商品頁接到後端 API 時，API 呼叫與資料轉換邏輯已有測試保護。

<objective>
建立 Phase 1 的端到端最薄切片：Vitest 可執行 → 環境變數決定 base URL → 新 axios client → `fetchProducts` 打 `GET /products` → 本機 dev proxy 真的讀到 production 商品 JSON。

Purpose: 完成後開發者立即能 `npm test`、能在本機 dev server 透過 `/api/v1/public/products` 取得後端資料，後續 plan（轉換、分類對照、錯誤處理）都在這條通路上加深。
Output: Vitest 設定、`.env.development`、`.env.example`、`src/services/apiTypes.ts`、`client.ts`、`products.ts` 與兩個測試檔。
</objective>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| 本地 main → origin/main | push 即觸發 Cloudflare Pages 正式部署 |
| 自動化流程 → 使用者同意 | orchestrator／子代理／自動模式不得代替使用者做上線決定 |
| GitHub → Cloudflare Pages 建置 | 線上 bundle 由 Cloudflare 重新建置，可能與本地不同 |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-11-02 | Elevation of Privilege | 未經同意 push main | mitigate | Task 2 為 `gate="blocking-human"` 的 checkpoint:decision，忽略 auto_advance／yolo；resume-signal 只接受使用者本人明確同意，其餘皆視為 hold；Task 3 hold 路徑不執行任何 push |
| T-11-07 | Tampering | push 內容與確認內容不符 | mitigate | push 前核對 `git rev-parse main` = 呈現的 MERGE_SHA、`origin/main..main` 清單一致；只執行 `git push origin main`，禁止 `--force`／`--all`／`--tags` |
| T-11-03 | Tampering | 線上 bundle 的 API base URL 錯誤 | mitigate | main build 後重跑 dist grep；部署後線上 bundle 檔名需等於本地，或下載線上 bundle 重跑同一組 grep（相對路徑 = 0、含正式網址） |
| T-11-01 | Information Disclosure | dist 憑證殘留 | mitigate | main 上 `npm run build` 內建 check-dist 通過才可進入 Task 2 |
| T-11-08 | Denial of Service | 部署失敗或上線後故障 | mitigate | 部署輪詢上限 20 分鐘並查 gh check-runs；SUMMARY 寫明 `git revert -m 1 MERGE_SHA` 回滾指引，回滾 push 同樣需使用者同意（D-07） |
| T-11-09 | Repudiation | 誰核准上線 | mitigate | SUMMARY 記錄使用者同意原文與時間 |
</threat_model>

## Phase Goal

**As a** 官網訪客, **I want to** 在 8 個商品分類頁與首頁熱銷輪播看到家人在後台維護的商品（含價格、載入中、失敗可重試、沒有商品的明確畫面）, **so that** 我看到的商品資訊與 KRD 實際上架的一致，遇到問題也知道發生什麼事。

<objective>
首頁切片：訪客打開首頁，兩組熱銷輪播分別顯示後台標為熱銷 1／熱銷 2 的商品，每組各自處理載入、失敗重試與沒有商品。

Purpose: 首頁是訪客第一眼看到的地方，目前沒資料時會永遠卡在「載入產品中...」。改由 useProducts 驅動後，家人在後台改熱銷設定，訪客重新整理即看到。Hero、標題區、CTA 區不動（使用者已說明視覺改版另開分支進行）。
Output: `FeaturedCarousel` 元件（從 `renderEnhancedCarousel` 搬出）、改寫的 HomePage，以及兩個測試檔。
</objective>
